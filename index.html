Criar uma Sala

Inicie uma nova sessão temporária para transmitir sua câmera, tela ou áudio.

  • Conexão P2P de Baixa Latência
  • Troca Dinâmica de Dispositivos

Entrar como Convidado

Insira um ID de sala para ligar sua câmera, interagir com os outros convidados e participar da transmissão no OBS.

Como usar no OBS

1. Crie uma sala e copie o link VIEW (Visualização).

2. Adicione uma Fonte de Navegador (Browser Source) no OBS.

3. Cole o link e adicione &obs=1 no final para ativar o modo transparente sem interface.
